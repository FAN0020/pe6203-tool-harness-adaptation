Offline verification

Unzip this supplement into a new directory. Python 3.12+ standard library is sufficient. No model key or network is needed.

python3 verify_supplement.py

This checks file hashes, extracts raw.tar.gz, blocks Python sockets and recomputes all four TF/PE scores, actual completion, calls, rejections, token-cost records and exact knowledge differences. The standalone replay explicitly skips the separate check of all old historical files. That preservation check was performed in the original repository, where 10,959 prior files matched their hashes.

Inspect raw evidence

tar -xzf raw.tar.gz
python3 audit.py --raw raw --output recomputed --skip-prior-evidence

raw/cells/{under_omitted,under_complete,over_reverted,over_note}/run contains events.jsonl, raw_trace.json, result.json, judge prompts, immutable judge-attempts, knowledge.json and environment-metadata.json. condition.json identifies the treatment. raw/frozen-source contains the source archive used for execution. Plan and ledger hashes preserve provenance. API keys are excluded.

Commands used for the approved executions

From the existing repository with its pinned MCP environments and private local .env:

uv run --no-sync --env-file .env python submission/diagnostics-20261031/driver.py prepare
uv run --no-sync --env-file .env python submission/diagnostics-20261031/driver.py run
python3 submission/diagnostics-20261031/audit.py

prepare refuses an existing output directory. run verifies the frozen plan and skips completed cells; it never replays an agent. Interrupted runs or unknown billing stop for review. The pinned runner's internal strategy label is selective_patch only because its API accepts a fixed set of labels; plan.kind and each condition.json explicitly mark these as controlled diagnostics, not natural main-method observations.
