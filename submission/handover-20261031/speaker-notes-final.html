Slide 1

20 seconds. Introduce the team and the research question: can selective changes to tool knowledge recover performance after environment changes while preserving unaffected capabilities? We use a fixed 27-trajectory benchmark and distinguish measured scores from execution completion and causal evidence.

Source: PE6203 Group Project 4 brief; archived course-v1.3 evidence.

Slide 2

40 seconds. Persistent changes to tool names, schemas and descriptions can invalidate an agent’s stored knowledge. Our first question is recovery: can adaptation restore performance on changed tasks? Our second is retention: can it preserve performance on tools that remain functional? A newly required parameter is a concrete example. We compare three update policies while holding the execution model and budget fixed.

Sources: PE6203 Group Project 4 brief; MCPEvol-Bench arXiv:2607.14642v1.

Slide 3

30 seconds. No Update retains Early knowledge. Full Rewrite rebuilds target tool records and asks the fixed model to rewrite all descriptions. Selective Patch uses metadata differences and dependencies to update affected records and preserve unaffected knowledge. All three use the same model to select tools and arguments. Because Full Rewrite generates descriptions while Patch copies authoritative metadata, this comparison changes both scope and generation mechanism; it is not a pure scope-only ablation.

Sources: frozen source commit12d693c, src/pe6203/selective.py and integration/baselines.py.

Slide 11
