PE6203 reproducibility package

Offline replay only. New model calls, diagnostics and deployments require approval.

Archived arithmetic

Unzip, enter the package directory, then use Python 3.12+ standard library. No credentials, project dependencies or network access are needed.

python3 reproduce/recalculate.py
python3 reproduce/verify_package.py

The first script reads the archive without extraction, verifies its identity and terminal-file hashes, parses 135 ratings and 27 cells, and recomputes TF/PE/ECS, recovery/retention and costs. It checks task/config/rubric consistency and execution endings. The second verifies packaged hashes and repeats arithmetic with sockets disabled and credential variables removed. Results must match the supplied metrics.json and cells.csv byte-for-byte. It also extracts and hashes all corpus members, then reproduces the 317-trajectory screening, candidate classifications and six negative diagnostic results.

Fresh behavioral reproduction: approval required

These commands document a fresh full reproduction, not a recommendation to repeat valid results. Provider behavior is stochastic, so fresh scores need not match. Restore the pinned official MCP environments through the bootstrap instructions. The full environment download is about3.4GB, expanding to roughly12GB, and is not bundled.

mkdir -p frozen-source
tar -xzf evidence/source-main-12d693c.tar.gz -C frozen-source
cd frozen-source
uv sync --frozen
npm install --prefix .cache/node-runtime --no-save --package-lock=false node@24.13.0
export MCPEVOL_NODE="$PWD/.cache/node-runtime/node_modules/node/bin/node"
uv run pe6203 bootstrap --scope all
