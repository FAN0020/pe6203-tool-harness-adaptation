Optional shared React/TSX build support is preinstalled. Both experiment methods receive this same input.
The external dependency directory in runtime.json contains React, ReactDOM, Motion, next-themes, canvas-confetti, Tailwind CSS and esbuild at locked versions. No install or network is needed for this build path.
Write your application entry at src/main.tsx. Imports beginning with @/ resolve to src/. Common cn and Button utilities and animation CSS are included; MagicUI component implementations are not prewritten here.
Run node build.cjs from the workspace. It writes public/app.js and public/styles.css. Create public/index.html yourself with links to styles.css and app.js and the application mount element. The builder does not generate HTML, application logic, input parsing or data.
Plain HTML/CSS/JavaScript remains acceptable; you can ignore the React build support.
