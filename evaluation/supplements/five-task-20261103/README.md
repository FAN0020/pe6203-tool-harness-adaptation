## Early与高分的解释

Early匹配只排除知识过时，不保证规划、工具运行、最终交付和模型评审满分。相同知识仍可产生不同轨迹；V3还附加能力边界文字，完整输入未必相同。不要把Early强制改成10分或按期望调整No Update分数。

235是不变工具的保持能力对照；430与90补充变化场景。扩大任务数可以改善覆盖，但不能消除批次、重复数、执行能力和评分的混杂。五次judge不是五次独立agent执行。
